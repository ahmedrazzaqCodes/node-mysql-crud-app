# Node.js User Management CRUD App

A beginner-friendly backend project built while learning Node.js, Express.js, EJS, and MySQL.

## About the Project

This application demonstrates how a web application communicates with a SQL database to display and manage user records.

## Features

- Home page
- View user records
- Edit usernames
- Delete user records
- Express routing
- EJS templates for rendering pages
- MySQL database integration

## Tech Stack

- Node.js
- Express.js
- EJS
- MySQL
- mysql2
- Git and GitHub

## Prerequisites

- Node.js and npm
- MySQL Server
- Git



## What I Learned

- Creating Express routes
- Handling form submissions and request bodies
- Passing data from Express to EJS templates
- Connecting Node.js to MySQL
- Writing SQL queries for user records
- Debugging database and routing errors
- Using Git to track development progress
